## 1. Project Overview

- **Project Name**: GRIDFRAME (formerly Glyphroom / icons workstation)
- **Version**: `0.1.0` (V2 Architecture)
- **Project Purpose**: A precision vector icon workstation, specimen library, and SVG engineering design tool for UI/UX designers and frontend developers. It allows users to browse 9,047+ normalized 24×24 vector icons (from Tabler, Phosphor, Lucide, and Heroicons), search with sub-millisecond scoring, live-customize vector attributes (stroke weight, dimensions, colors, rotations, flip transforms), export into multiple formats (Clean Raw SVG, React TSX, HTML Snippet, Data URI, CSS Mask), curate custom icon sets/favorites with schema-versioned local storage, and inspect canonical icon geometry and optical bounds in an integrated QA suite.
- **Frontend Framework**: React 18 (`react@^18.3.1`, `react-dom@^18.3.1`) with TypeScript (`typescript@^5.7.3`)
- **Build Tool**: Vite (`vite@^6.2.0`) with `@vitejs/plugin-react@^4.3.4`
- **Package Manager**: npm (Node.js ecosystem)
- **Styling Approach**: Semantic Design Token System (CSS Custom Properties & SCSS tokens) mapped via Tailwind CSS (`tailwindcss@^3.4.17`), PostCSS (`postcss@^8.5.3`), and Autoprefixer (`autoprefixer@^10.4.20`).
- **UI / Component Libraries**: Custom hand-crafted design system primitives (`Button`, `IconButton`, `Input`, `Modal`, `Badge`, `Slider`, `Toast`, `Separator`), selective Skiper micro-interaction utilities (`SkiperThemeToggle`, `SkiperTooltip`, `SkiperSegmentedTabs`, `SkiperButton`), and `lucide-react@^1.16.0` for interface utility icons.
- **State Management**: React Context API (`ThemeContext`, `ToastContext`, `LenisContext`, `SearchContext`) + Custom Hooks with schema-versioned `localStorage` synchronization (`useFavorites`, `useCollections`, `useLocalStorage`, `useIconCustomizer`).
- **API / Data-Fetching**: Local-first vector asset catalog (`catalog.json` with 5,130+ items) loaded statically into memory. No remote external backend dependencies required for core functionality.
- **Authentication**: Not implemented (Local-first anonymous client workstation architecture).
- **Deployment & Production Build**: Static SPA compilation outputting to `dist/` with Rollup vendor chunk splitting (`vendor-react`, `vendor-motion`, `vendor-icons`, `vendor-lenis`).

## 6. Pages / Screens

### 1. Main Icon Workstation (`IconsRoute.tsx`)
- **Path**: `src/routes/IconsRoute.tsx`
- **Route**: `/icons`
- **Purpose**: Primary specimen discovery workstation. Presents left-aligned editorial heading, command search trigger, horizontal category scroll strip, style filters, curated domain sections (`Core Essentials`, `Navigation`, `Development`, `Commerce`), and a performant infinite-scrolled specimen grid.
- **Main Components**: `WorkspaceShell`, `ExplorerToolbar`, `SpecimenCard`, `SpecimenGrid`, `IconDetailModal`, `CommandPalette`
- **Data Sources**: `src/data/icons/gridframe-catalog.ts` (5,130+ vector items)
- **State**: `query`, `category`, `style`, `sort`, `selectedIcon`, `isCommandPaletteOpen`
- **User Actions**: Real-time search, category switching, style toggling, sorting (popular, newest, A–Z, Z–A), opening detail modal, bookmarking favorites, triggering ⌘K.

### 2. Category Hub (`CategoriesRoute.tsx`)
- **Path**: `src/routes/CategoriesRoute.tsx`
- **Route**: `/categories` & `/categories/:category`
- **Purpose**: Directory of 20 semantic design domains (Navigation, Arrows, Commerce, Development, Security, etc.) with icon metrics. When a category is clicked, renders the filtered specimen grid.
- **Main Components**: `WorkspaceShell`, `SpecimenGrid`, `IconDetailModal`, `Button`
- **Data Sources**: `ALL_CATEGORIES` list + `GRIDFRAME_ICONS`

### 3. Vector Styles Hub (`StylesRoute.tsx`)
- **Path**: `src/routes/StylesRoute.tsx`
- **Route**: `/styles` & `/styles/:style`
- **Purpose**: Directory of vector stroke styles (`Outline / Linear` vs `Filled / Solid`). Filters catalog by variant style.
- **Main Components**: `WorkspaceShell`, `SpecimenGrid`, `IconDetailModal`

### 4. Saved Favorites (`FavoritesPage.tsx`)
- **Path**: `src/features/favorites/FavoritesPage.tsx`
- **Route**: `/favorites`
- **Purpose**: Allows users to manage bookmarked icons, filter among saved items, batch-download all bookmarked SVGs, or clear favorites.
- **Main Components**: `WorkspaceShell`, `SpecimenGrid`, `IconDetailModal`, `Button`, `Input`
- **State**: `useFavorites` hook (`localStorage` key `gridframe_favorites_v2`)

### 5. Collections Studio (`CollectionsRoute.tsx`)
- **Path**: `src/routes/CollectionsRoute.tsx`
- **Route**: `/collections` & `/collections/:id`
- **Purpose**: Custom set builder. Allows grouping icons into named project collections, editing metadata, and batch-exporting entire sets.
- **Main Components**: `CollectionList`, `CollectionDetailPage`, `CollectionDialog`, `CollectionCard`

### 6. Design System Specification (`DesignSystemRoute.tsx`)
- **Path**: `src/routes/DesignSystemRoute.tsx`
- **Route**: `/dev/design-system`
- **Purpose**: Interactive QA showcase displaying color matrices, type scales, spacing tokens, button/input states, interactive specimen cards, toast triggers, and canonical 24×24 icon grid guides.

### 7. Optical System QA (`QARoute.tsx` / `IconSystemQA.tsx`)

## 19. Animations & Interactions

## 21. Performance

- **Lazy Loading & Virtualization**: `SpecimenGrid.tsx` uses an `IntersectionObserver` batching system (64 items per chunk) to smoothly render 5,000+ icons without DOM bloat.
- **CSS Containment**: `.contain-specimen-tile { contain: layout style paint; }` eliminates redundant reflows.
- **Memoization**: Heavy SVG transformations and search filters are wrapped with `useMemo` and `useCallback`.
- **Bundle Optimization**: Rollup vendor chunking (`vendor-react`, `vendor-motion`, `vendor-icons`, `vendor-lenis`).

## 26. Code Quality & Architecture Review

### Strengths
- **Decoupled Design Tokens**: Strict separation of design tokens (`tokens.scss`, `tokens.css`) from component JSX.
- **Specimen-First UX**: Avoids generic SaaS clutter; focuses on large vector rendering and fast developer workflows.
- **Robust SVG Pipeline**: Full SVG sanitization, normalization, and optical geometry analysis scripts.
- **Non-Interfering Scrolling**: Lenis smooth scrolling with clean `data-lenis-prevent` boundaries for modals and code blocks.

### Identified Technical Debt & Risks
- Large in-memory catalog (`catalog.json` ~586KB): Could benefit from gzip/brotli pre-compression or dynamic chunking for low-bandwidth networks.
- Some legacy component files (`DetailPanel.tsx`, `WorkspaceLayout.tsx`) remain from V1 right-sidebar architecture and can be archived.
