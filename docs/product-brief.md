# Glyphroom — Product Brief & Vision

## 1. Executive Summary
**Glyphroom** is a focused, high-performance icon workstation engineered specifically for product designers and software engineers. Rather than functioning as a standard marketing catalog or static icon pack website, Glyphroom operates as a professional browser-based design tool. It empowers users to discover, inspect, compare style variants, customize visual parameters (color, stroke weight, stroke cap/join, rotation, flip, size), and export production-grade code (clean SVG, React components, HTML) in just a few keystrokes or clicks.

## 2. Core Value Proposition
- **High-Velocity Discovery:** Instant fuzzy/keyword search with sub-50ms latency, deep category filtering, style switching, and keyboard navigation.
- **Context-Preserving Workspace:** A 3-part layout (Discovery, Exploration, Inspection) that keeps the primary icon grid visible while customizing and comparing variants in a persistent side panel.
- **Precision Customizer:** Live vector manipulation allowing real-time adjustments to stroke width, stroke caps/joins, dimensions, colors, transform rotations, and preview backgrounds.
- **Zero-Friction Code & Asset Export:** One-click copy for optimized SVG, JSX/TSX React components, vanilla HTML snippets, and instant SVG/PNG downloads with sanitize-safe output.
- **Local-First Persistence:** Collections, favorites, recent history, theme, and grid density settings persisted entirely via local storage without mandatory accounts.

## 3. The Core Product Loop
1. **Search / Filter:** Input query or select tags, styles, and categories.
2. **Explore:** Scan the responsive icon grid with smooth hover interactions and quick actions.
3. **Select:** Open the contextual detail panel without losing position in the grid.
4. **Compare Variants:** Switch between styles (Linear, Outline, Bold, Filled, Duotone, Two-tone, Broken, Mono) for the same icon concept.
5. **Customize:** Tweak stroke width, caps, joins, rotation, flip, canvas scale, and colors.
6. **Export / Copy:** Copy production-ready SVG/React code or download optimized files.
7. **Organize:** Save to custom collections or favorites for ongoing project workflows.

## 4. Target Personas
- **UI/UX Designers:** Seeking consistent iconography sets with flexible stroke weights and style variants matching design system specifications.
- **Frontend Engineers:** Needing fast, accessible, and clean SVG/React code without bloated attributes or manual cleanup.
- **Design Engineers & Prototypers:** Requiring quick access to varied icon styles for rapid product prototyping.
